# Backrow

A media client for YouTube on Android TV, Google TV and Fire OS, operated entirely with a remote control. Open source, Apache-2.0.

Backrow is not affiliated with, endorsed by, or sponsored by Google or YouTube.

**Status:** pre-alpha. Nothing to install yet.
